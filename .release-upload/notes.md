# Probabilistic Rune Downgrade 0.1.1

악마술사의 군림 오프라인용 D2RMM 모드입니다. 제작자: 빵길빵길.

## 변경 내용

분해 대기 아이템에 바론9님의 Glowing Runes 아이콘을 적용합니다. 일반 룬 아이콘과 확률 설정·조합 규칙은 유지합니다. 새로운 이미지·표시와 저장/재접속은 실제 게임 검증 전이므로 사전 릴리스로 제공합니다. 자동 생성기 검사는 45개를 통과했습니다.

## 설치

첨부 ZIP은 사용자가 제공한 파일을 재압축 없이 그대로 게시한 것입니다. 최상위에 mod.js, mod.json, hd 폴더가 있습니다.

1. 게임을 종료하고 캐릭터와 공유 보관함을 백업합니다.
2. ZIP 내용을 **D2RMM/mods/ProbabilisticRuneDowngrade/** 폴더 안에 풉니다. 그 위치에 mod.json과 mod.js가 있어야 합니다. D2RMM 루트나 게임 data 폴더에 직접 풀지 마세요.
3. 모드를 선택하고 Install Mods를 실행합니다. Relics of Sanctuary 병용 시 우리 모드를 그 뒤에 둡니다.

모드 구성·순서·게임 버전 변경 전에는 대기 아이템을 모두 처리하고 저장을 백업하세요.
