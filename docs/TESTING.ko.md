# 검증 기록 및 추가 확인 방법

## 사용자 보고로 확인한 범위

악마술사의 군림용 오프라인 환경에서 단독 테스트는 D2RMM 1.9.2, 기존 모드 병용 테스트는 D2RMM 1.9.0으로 진행했습니다. 실제 게임 빌드 및 전체 활성 모드 목록은 확보하지 못했습니다.

- 설치 오류를 수정한 뒤 설치 완료.
- 네 결과와 수량, 조드부터 엘까지 분해 진행.
- 반환/성공 룬의 기존 업그레이드 조합, 소켓, 시험용 룬워드 사용.
- 단독 시험 및 기존 모드 병용 환경에서 대기 아이템 저장·종료·재접속 후 재조합.
- Relics of Sanctuary 병용 시 대기 아이템에 저항 감소 속성이 생기고 재조합이 안 되던 문제는 동일한 Mythic 속성 중복 등록 호환 처리 후 사용자 보고상 정상 실행.

기존 모드 병용 환경의 25/25/25/25 설정 100회:

| 결과 | 횟수 |
|---|---:|
| 하위 룬 2개 | 27 |
| 하위 룬 1개 | 25 |
| 입력 룬 유지 | 23 |
| 감별 주문서 — 꽝 | 25 |

이 기록은 기능 확인과 설정 분포에 대한 표본이며 모든 모드·패치의 호환성이나 난수 분포를 증명하지 않습니다.

정식 GitHub 배포본으로도 D2RMM 1.9.0 병용 환경에서 25%씩 설정하여 50회를 추가 테스트했습니다. 결과는 하위 2개 9회, 하위 1개 15회, 유지 10회, 꽝 16회였으며 정상 실행됐습니다. 병용 환경에는 Relics, 룬 겹치기, 타락 모드가 포함됩니다.

단독 환경(D2RMM 1.9.2)에서는 네 결과 각각 100% 설정 확인과 기본 확률 50/25/10/15에서 41회 테스트를 진행했습니다. 41회 결과는 하위 2개 24회, 하위 1개 10회, 유지 2회, 꽝 5회입니다.

## 정식 버전 변경 및 로컬 검증

0.1.0은 사용자가 제공한 테스트 완료 mod.js를 기준으로 이름·제작자·버전을 정리하고 이스트 전용 옵션을 제거했습니다. 이제 항상 32등급/3,232개 조합을 생성합니다. 이전 설정 파일에 istOnly=true가 남아 있어도 무시합니다.

`node tools/verify.mjs`의 검사 결과는 LOCAL_VALIDATION.json에 있습니다. 합성 fixture의 생성/분포/설정 오류/스탯 보존/중복 Mythic 호환 검사를 수행하며 실제 게임 실행을 대신하지 않습니다. 사용자가 제공한 최종 TSV 4개를 이용한 별도 생성기 검사도 수행했습니다. 미제공 테이블 및 문자열/HD는 합성 자료로 보완했습니다.

## 새 환경에서 짧게 확인하려면

1. 캐릭터·공유 보관함을 백업하고 복사한 시험용 세이브를 사용합니다.
2. 확률을 각각 100%로 설정해 네 결과를 한 번씩 확인합니다. 설정 변경 전 대기 아이템을 모두 처리하고 게임을 종료한 뒤 재설치합니다.
3. 기본 확률에서 대기 아이템 하나를 만들어 저장·종료·재접속한 뒤 단독 재조합합니다.
4. 다른 모드와 병용 시 설치 로그, 입력·출력·수량과 표시 이상 여부를 확인합니다. 대량 반복은 필수가 아닙니다.

모드 제거·순서 변경·게임 업데이트 전 모든 대기 아이템을 처리하세요. 잘못 생성된 이전 대기 아이템의 자동 복구는 보장하지 않습니다.
