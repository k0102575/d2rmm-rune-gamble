# 게임 검증 체크리스트

## 로컬에서 확인한 범위

`LOCAL_VALIDATION.json`의 PASS는 Node VM에서 D2RMM API를 모의한 설치 생성기 검사다. 기본 101행, 전체 3,232행, 모든 등급/추첨값의 단일 분기와 기본 분포 50/25/10/15, 네 결과 각각 100% 설정, 0% 구간, 악마술사의 군림 경로 고정, 잘못된 설정/스택/ID/컬럼/이름 충돌에서 쓰기 없이 실패하는 것을 검사했다. 공개 수정 테이블을 사용한 전체 생성도 통과했다. D2RMM 앱 설치와 실제 게임 테스트는 미실행이다.

## 사용자 게임 테스트 순서

1. 게임/D2RMM 버전과 모드 목록·순서를 기록한다. 악마술사의 군림 오프라인 캐릭터인지 확인한다. 캐릭터·공유 보관함을 백업하고 복제한 시험용 캐릭터를 사용한다. 다른 모드는 끈다.
2. 기본 Ist-only로 설치한다. 이스트 1 + 낱장 감별 주문서 1 → 대기 아이템 **정확히 1개**, 입력 둘은 없어지는지 확인한다. 이름과 추가 조합 안내가 한국어/영어로 보이는지, 대기 이름이 `이스트룬 — 분해 대기`이며 원래 이스트룬 아이콘이 HD/레거시에서 정상인지 확인한다.
3. 대기 아이템 **하나만** 넣고 조합한다. 말 2 / 말 1 / 이스트 1 / 감별 주문서 1 중 정확히 하나인지 확인한다. 성공·유지에는 주문서가 없어야 한다. 추가 재료나 대기 아이템 여러 개를 넣었을 때 의도하지 않은 조합이 없어야 한다.
4. 대기 아이템을 모두 처리한 뒤 확률을 100/0/0/0으로 재설치하여 말 두 개를 검증한다. 이어 0/100/0/0, 0/0/100/0, 0/0/0/100으로 각각 반복한다. 각 경우 첫 단계에서 만드는 대기 아이템은 새로 만든다. 이 검사가 속성 추첨·조건·출력 슬롯의 최소 검증이다.
5. 기본 확률로 복원한다. 대기 아이템을 만든 뒤 저장 종료/재접속/개인 및 공유 보관함 이동 후 정상 해소되는지 확인한다. 동일 백업 대기 아이템을 복원·재조합해 결과가 유지되는지 확인한다. 저장 호환 확인 전 본 세이브에 적용하지 않는다.
6. 반환/성공 룬을 툴팁과 원래 업그레이드 조합, 소켓, 시험용 룬워드에 사용해 깨끗한 일반 룬인지 확인한다. 대기 아이템은 소켓 삽입·장착·참 재조합·주문서 사용을 할 수 없어야 한다.
7. 대기 아이템을 모두 처리한 뒤 Ist-only를 끄고 재설치한다. 엘드는 엘로, 조드는 참으로 분해되고 엘은 조합되지 않는지 확인한다. 나머지 30등급도 두 단계 조합을 확인한다. 특히 추가된 전체 표에서 설치 시간, 게임 로드, 큐브 반응 지연/충돌을 기록한다.
8. 기본 확률로 1,000회 이상 가능하면 결과별 횟수를 기록한다. 기대 횟수는 500/250/100/150이나 정확히 일치할 필요는 없다. 소표본에서 비율이 다른 것만으로 실패라 판단하지 않는다. 단일 출력 위반/해소 불가/예상 외 아이템은 즉시 실패로 기록한다.
9. Normal/Nightmare/Hell에서 확인한다. 모드 조합은 단독 통과 후 백업 시험 세이브로 하나씩 추가한다. 기존 레저렉션 캐릭터는 지원 대상이 아니다.

## 오류 보고 양식

- 게임 빌드 / D2RMM 버전 / 악마술사의 군림 캐릭터 여부 / 언어 / HD·레거시:
- 모드 버전 / 순서 / 확률 / Ist-only:
- 입력 / 실제 출력 / 기대 출력 / 저장·재접속 여부:
- 재현 단계 / 설치 오류 전문 / 스크린샷:

모드 제거·순서 변경 전 모든 대기 아이템을 처리한다. 확률 변경은 기존 대기값을 새 구간으로 재해석한다. 변경 상태의 저장 호환 시험은 폐기 가능한 복사본에서만 수행한다.
