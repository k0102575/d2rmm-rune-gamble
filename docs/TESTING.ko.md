# 게임 검증 체크리스트

## 이번에 부탁드리는 테스트 범위

**150회나 1,000회씩 반복할 필요는 없습니다.** 우선 아래의 짧은 기능 테스트만 진행해주세요. 목적은 네 결과와 저장 기능이 정상인지 확인하는 것입니다. 확률이 통계적으로 정확한지 증명하는 테스트는 아닙니다.

- 네 결과를 각각 100%로 설정해 한 번씩 확인: 총 4회
- 대기 아이템 상태로 저장·종료하고 재접속한 뒤 결과 확인: 1회
- 기본 확률로 10~20회 정도 사용: 권장 범위이며, 재료가 부족하면 가능한 만큼만 진행

여기서 **1회는 ‘룬 + 감별 주문서 조합 → 대기 아이템 단독 재조합’까지 한 세트**입니다. 큐브 버튼은 보통 한 세트에 두 번 누릅니다. 위 범위대로라면 총 15~25세트입니다. 대량 반복이나 상세한 결과 집계는 요청하지 않습니다.

## 로컬에서 확인한 범위

`LOCAL_VALIDATION.json`의 PASS는 Node VM에서 D2RMM API를 모의한 설치 생성기 검사입니다. 기본 101행, 전체 3,232행, 모든 등급/추첨값의 단일 분기와 기본 분포 50/25/10/15, 네 결과 각각 100% 설정, 0% 구간, 악마술사의 군림 경로 고정, 이름·그림 연결, 잘못된 설정/스택/ID/컬럼/이름 충돌에서 쓰기 없이 실패하는 것을 검사했습니다. 공개 수정 테이블을 사용한 전체 생성도 통과했습니다.

이는 조합 데이터 생성에 대한 검사입니다. D2RMM 앱 설치와 실제 게임 실행은 아직 검증하지 않았습니다.

## 우선 진행할 짧은 기능 테스트

### 1. 준비

게임/D2RMM 버전과 모드 목록·순서를 기록합니다. 악마술사의 군림 오프라인 캐릭터인지 확인하고, 캐릭터·공유 보관함을 백업합니다. 복제한 시험용 캐릭터를 사용하고 다른 모드는 끕니다. `Ist-only prototype`은 켜 둡니다.

### 2. 네 결과를 한 번씩 확인

D2RMM에서 아래 순서대로 확률을 설정하고, **설정할 때마다 Install Mods로 재설치**합니다. 게임을 종료한 상태에서 설정을 바꾸세요.

| 하위 룬 2개 | 하위 룬 1개 | 원래 룬 반환 | 꽝 | 이스트 입력 시 기대 결과 |
|---|---|---|---|---|
| 100 | 0 | 0 | 0 | 말룬 2개 |
| 0 | 100 | 0 | 0 | 말룬 1개 |
| 0 | 0 | 100 | 0 | 이스트룬 1개 |
| 0 | 0 | 0 | 100 | 감별 주문서 1개 |

각 설정에서 이스트룬 1개 + 낱장 감별 주문서 1개를 조합합니다. 입력 둘이 사라지고 대기 아이템이 정확히 1개 나와야 합니다. 이름은 `이스트룬 — 분해 대기`, 그림은 이스트룬이며, 추가 재료 없이 단독 재조합하라는 안내가 보여야 합니다.

그 대기 아이템 **하나만** 넣고 다시 조합해 표의 결과가 나오는지 확인합니다. 성공·유지 결과에는 감별 주문서가 추가로 나오면 안 됩니다.

**설정을 바꾸기 전에 대기 아이템을 모두 처리하고, 다음 설정에서는 새 대기 아이템을 만드세요.** 기존 대기 아이템은 변경한 확률에 따라 결과가 재해석되기 때문입니다.

### 3. 저장·재접속 확인

확률을 기본값 **50/25/10/15**로 되돌리고 재설치합니다. 대기 아이템을 하나 만든 뒤 저장·종료합니다. 재접속했을 때 이름·그림이 정상이고, 단독 재조합하면 네 결과 중 하나가 나오는지 확인합니다.

### 4. 기본 확률로 짧게 사용

기본 확률에서 10~20회 정도 조합해 봅니다. 재료가 부족하면 가능한 만큼만 하고 횟수를 알려주세요.

확인할 것은 조합 불가, 대기 아이템 소실, 예상 외 아이템, 잘못된 수량, 성공 시 주문서 추가 반환 같은 기능 오류입니다. 결과별 횟수를 세거나 표로 정리할 필요는 없습니다. **이 정도 횟수로 50/25/10/15가 맞는지 판정하지 않습니다.** 특정 결과가 안 나오거나 연속으로 나오는 것만으로 오류라고 판단하지 마세요.

## 결과는 이렇게만 알려주세요

문제가 없으면 아래 정도면 충분합니다.

```text
게임 빌드 / D2RMM 버전:
100% 설정 네 가지: 모두 정상 (또는 실패한 항목)
대기 아이템 저장·재접속: 정상 / 문제 있음
기본 확률: 약 N회, 이상 없음 / 문제 있음
```

문제가 생겼을 때만 사용한 확률, 입력과 실제 출력, 재현 단계, 설치 오류 전문 또는 스크린샷을 덧붙여주세요. 테스트하지 않은 항목은 ‘미실행’으로 적으면 됩니다.

## 나중에 여유가 있으면 할 추가 검증 — 선택 사항

아래는 이번 짧은 테스트의 완료 조건이 아닙니다. 모두 수행하거나 대량 반복 결과를 제출할 필요는 없습니다.

- 반환/성공 룬을 기존 업그레이드 조합, 소켓, 시험용 룬워드에 사용해 일반 룬처럼 동작하는지 확인
- 대기 아이템의 개인·공유 보관함 이동, 일반 참 조합이나 소켓에 잘못 사용되지 않는지 확인
- 대기 아이템을 모두 처리한 뒤 Ist-only를 끄고, 엘드→엘·조드→참과 엘의 분해 불가 확인. 나머지 등급은 차후 필요할 때 확인
- Normal/Nightmare/Hell, HD/레거시 표시, 전체 조합 추가 후 로드·큐브 반응 확인
- 확률 분포 확인은 장기간 플레이에서 자연스럽게 쌓인 기록이 있을 때만 검토. 최소 반복 횟수나 제출 의무 없음

짧은 기능 테스트가 통과해도 전체 등급·다른 모드와의 호환성·확률 분포까지 검증됐다는 뜻은 아닙니다. 확인한 범위와 미실행 범위를 구분해 기록합니다.

모드 제거·순서 변경·게임 업데이트 전 모든 대기 아이템을 처리하세요. 저장 호환 확인 전 본 세이브에는 적용하지 마세요.
