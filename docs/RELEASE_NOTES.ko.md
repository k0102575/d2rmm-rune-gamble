# Probabilistic Rune Downgrade 0.1.0

제작자: **빵길빵길**. 악마술사의 군림 전용 오프라인 D2RMM 모드입니다.

룬 1개와 낱장 감별 주문서 1개를 조합하면 대기 아이템이 나옵니다. 그 아이템만 추가 재료 없이 다시 조합하면 결과를 받습니다. 첫 조합에서 추첨값을 저장하고 두 번째 조합에서 결과를 지급하는 방식입니다.

엘드부터 조드까지 전체 32등급의 룬을 분해할 수 있으며 엘은 분해하지 않습니다. 기본 확률은 하위 룬 2개 50%, 하위 룬 1개 25%, 입력 룬 유지 10%, 감별 주문서 1개가 나오는 꽝 15%입니다. 네 확률은 각각 0에서 100 사이의 정수로 설정하고 합계를 100으로 맞춥니다.

## 검증 범위

제작자의 실제 플레이 환경에서 다음과 같이 테스트했습니다. 결과 순서는 **하위 룬 2개 / 하위 룬 1개 / 입력 룬 유지 / 꽝**입니다.

| 환경 | 설정 확률 | 테스트 내용 | 결과 횟수 |
|---|---|---|---|
| D2RMM 1.9.2, 이 모드만 설치 | 각 결과를 차례로 100% 설정 | 네 결과와 수량 확인 | 모두 정상 |
| D2RMM 1.9.2, 이 모드만 설치 | 기본값 50 / 25 / 10 / 15 | 41회 | 24 / 10 / 2 / 5 |
| D2RMM 1.9.0, 기존 모드들과 병용 | 25 / 25 / 25 / 25 | 정식 배포 전 100회 | 27 / 25 / 23 / 25 |
| D2RMM 1.9.0, 기존 모드들과 병용 | 25 / 25 / 25 / 25 | GitHub 정식 배포본으로 50회 | 9 / 15 / 10 / 16 |

병용 환경에는 Relics of Sanctuary, 룬 겹치기, 타락 모드가 포함되어 있습니다. Relics 호환 처리 후 조합과 결과 지급이 정상 동작했습니다.

확률별 반복 테스트와 별도로 다음 공통 기능도 확인했습니다.

- 조드부터 엘까지 하위 룬으로 분해하는 과정과 네 결과의 지급 수량
- 분해로 얻은 하위 룬의 **룬워드 조합, 룬 창고 저장, 룬 겹치기**
- 반환·성공 룬의 기존 업그레이드 조합 및 소켓 사용
- **저장 후 게임 종료·재접속** 및 결과 룬 확인
- 대기 아이템 상태에서 저장·종료·재접속 후 단독 재조합

룬 겹치기 등 다른 모드의 기능은 해당 모드를 함께 사용하는 환경에서 확인했습니다.

위 기록은 테스트한 환경의 결과이며 모든 게임 패치와 모드 조합의 호환성을 보장하지는 않습니다. 반복 횟수만으로 설정 확률의 정확성이 완전히 증명되는 것은 아닙니다. 로컬 생성기 검사와 실제 게임 검증은 구분합니다. [검증 기록](docs/TESTING.ko.md), [로컬 검사](docs/LOCAL_VALIDATION.json), [구현 기록](docs/IMPLEMENTATION.md)을 참고하세요.

## 저장 및 모드 구성 변경 주의

모드를 제거하거나 순서·구성·게임 버전을 바꾸기 전에는 대기 아이템을 모두 재조합해 처리하고 저장을 백업하세요. 대기 아이템을 남겨 둔 채 확률을 바꾸면 저장된 추첨값에 새 확률이 적용됩니다. 테스트하지 않은 모드 조합이나 예상치 못한 상호작용으로 충돌이 발생할 수 있습니다.
