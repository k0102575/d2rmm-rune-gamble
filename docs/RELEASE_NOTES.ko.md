악마술사의 군림(Reign of the Warlock) 전용 오프라인 D2RMM 모드의 수정 시험판입니다.

**실제 게임 검증 전입니다. 정식 안정 버전이 아닌 사전 릴리스입니다.**

### alpha.2 수정 및 재시험

설치 성공 후 이스트+감별 주문서 조합이 무반응이라는 보고를 받았습니다. 대기 아이템 코드를 D2R HD 매핑에 맞는 3글자로 변경했습니다. 증상 해결은 아직 게임 재검증 전입니다. 이번에는 먼저 첫 조합과 대기 아이템 단독 재조합을 한 번씩만 확인해주세요.

이전 시험판의 대기 아이템은 새 코드와 저장 호환되지 않습니다. 백업한 시험용 저장을 사용하세요. 첫 조합이 안 돼 대기 아이템이 생성되지 않았던 경우에는 이관할 아이템이 없습니다.

### 설치

1. 아래 Assets에서 `ProbabilisticRuneDowngrade-0.1.0-alpha.2.zip`을 다운로드합니다. GitHub가 자동 생성하는 `Source code` ZIP은 설치용이 아닙니다.
2. 게임을 종료하고 오프라인 캐릭터와 공유 보관함을 백업합니다.
3. ZIP을 D2RMM 루트에 풉니다. `mods/ProbabilisticRuneDowngrade/mod.json` 경로를 확인합니다.
4. D2RMM 1.9+에서 모드를 선택하고 Install Mods를 실행합니다. 처음에는 기본 `Ist-only prototype`으로 시험하세요.

### 동작

이스트룬 1개 + 감별 주문서 1개 → 이스트룬 그림의 `분해 대기` 아이템 → 추가 재료 없이 단독 재조합 → 결과.

기본 확률: 하위 룬 2개 50%, 하위 룬 1개 25%, 원래 룬 반환 10%, 감별 주문서 1개 15%. 네 확률은 설정할 수 있으며 정수 합계가 100이어야 합니다. 기본은 이스트→말 시제품이며, Ist-only를 끄면 엘드~조드 전체 조합을 생성합니다.

### 검증 범위와 저장 주의

- 로컬: 모의 D2RMM 실행으로 23개 시나리오 통과. 공개 수정 테이블을 사용한 생성 검사 포함.
- 릴리스 CI: 저장소의 합성 fixture로 조합 생성·확률·그림·이름 및 오류 차단 검사 후 ZIP 제작.
- 미검증: 실제 D2RMM 설치, 게임의 난수 속성 적용, 저장·재접속, 결과 룬의 소켓/룬워드 사용. 동봉한 `docs/TESTING.ko.md`의 짧은 기능 테스트부터 확인해주세요. 네 결과 각각 100% 설정·저장 및 재접속 확인 후 기본 확률로 10~20회 정도 사용하면 됩니다. 대량 반복이나 결과별 집계는 요청하지 않습니다.
- 모든 대기 아이템을 처리한 뒤 모드 제거·순서 변경·게임 업데이트를 하세요. 확률 변경은 기존 대기값의 결과를 재해석합니다.
- 다른 룬 분해·룬 스택·타락 모드는 끄고 시험하세요.

ZIP 내부 파일별 SHA-256 목록과 ZIP 자체의 `.sha256` 파일을 제공합니다. 게임 원본 테이블·이미지 파일은 배포하지 않습니다.
