# Probabilistic Rune Downgrade — 0.1.0

제작자: **빵길빵길**. 악마술사의 군림(Reign of the Warlock) 전용 오프라인 D2RMM 모드입니다.

룬 1개 + 낱장 감별 주문서 1개 → 분해 대기 아이템 → 추가 재료 없이 대기 아이템만 다시 조합하여 결과를 받습니다.

| 결과 | 기본 확률 |
|---|---:|
| 바로 아래 룬 2개 | 50% |
| 바로 아래 룬 1개 | 25% |
| 입력 룬 1개 반환 | 10% |
| 감별 주문서 1개 — 꽝 | 15% |

엘드(r02)~조드(r33) 전체 32등급을 항상 지원합니다. 엘(r01)은 분해하지 않습니다. 이스트 전용 옵션은 제거했습니다. 네 확률만 설정할 수 있으며, 각각 0~100 정수이고 합계가 정확히 100이어야 합니다. 첫 조합에서 입력 룬과 주문서를 소비하며 성공/유지에는 주문서를 돌려주지 않습니다.

## 설치

1. 게임을 종료하고 오프라인 캐릭터와 공유 보관함을 백업합니다.
2. `ProbabilisticRuneDowngrade-0.1.0.zip`을 D2RMM 루트 폴더에 풉니다. `mods/ProbabilisticRuneDowngrade/mod.json`이 있어야 합니다.
3. D2RMM 1.9 이상에서 **Probabilistic Rune Downgrade**를 선택하고 확률을 설정합니다.
4. Relics of Sanctuary와 함께 사용한다면 우리 모드를 그 뒤에 두고 Install Mods를 실행합니다.
5. D2RMM 설정에 맞게 오프라인 게임을 실행합니다. 기존 게임 캐릭터 버전 호환성을 확대해 주장하지 않으며 악마술사의 군림용 데이터 `global/excel`만 생성합니다.

## 검증 범위

사용자 보고로 D2RMM 1.9.2 설치, 네 결과, 조드부터 엘까지 진행, 결과 룬의 업그레이드·소켓·시험용 룬워드, 대기 아이템 저장·종료·재접속 후 재조합을 확인했습니다. Relics를 포함한 사용자의 기존 모드 구성에서 호환 처리 후 100회 정상 실행됐습니다. 25/25/25/25 설정의 결과는 하위 2개 27회, 하위 1개 25회, 유지 23회, 꽝 25회였습니다.

검증한 구성에서의 결과이며 모든 모드 조합이나 게임 패치의 호환성을 보장하지 않습니다. 테스트한 게임 빌드와 전체 모드 목록은 확보하지 못했습니다. 로컬 생성기 검사와 게임 검증은 구분합니다. [검증 기록](docs/TESTING.ko.md), [로컬 검사](docs/LOCAL_VALIDATION.json), [구현 기록](docs/IMPLEMENTATION.md)을 참고하세요.

## Relics of Sanctuary 호환 및 저장 주의

Relics가 완전히 같은 `item-mythic` 속성을 두 번 등록하면 두 번째 이후 속성의 내부 코드에 별칭을 부여합니다. 첫 Mythic 정의와 모든 행 위치·스탯은 유지하고 Relics 소스는 수정하지 않습니다. 내용이 서로 다르면 설치를 중단합니다. 기타 중복 코드의 자동 복구는 제공하지 않습니다.

**모드 제거·순서 변경·다른 스탯 추가 모드 설치·게임 업데이트 전 대기 아이템을 모두 처리하고 저장을 백업하세요.** 추첨값은 첫 조합에서 고정됩니다. 대기 아이템을 남겨 둔 채 확률만 바꾸면 저장된 값에 새 확률이 적용되어 결과가 재해석됩니다. 스탯 ID는 현재 테이블 끝에 추가되므로 모드 구성이나 순서 변경으로 저장 호환성이 달라질 수 있습니다. 이전에 잘못 생성된 대기 아이템의 자동 복구는 보장하지 않습니다.

다른 룬 분해·룬 겹치기·단일 룬 업그레이드·타락·대규모 모드는 충돌할 수 있습니다. Relics 병용 검증을 다른 모드 전체에 일반화하지 마세요.

## 개발 및 배포물 제작

Node.js 18+에서 `node tools/verify.mjs`, Python 3에서 `python3 tools/build.py`를 실행합니다. 합성 fixture로 설치 생성기를 검사하고 ZIP 내부 파일별 SHA-256 및 ZIP 자체의 SHA-256 파일을 생성합니다. 공개 조사 테이블이 준비된 경우에만 해당 원문을 사용하는 별도 검사를 실행합니다. 게임 원본 테이블·이미지 및 타 모드 소스를 배포하지 않습니다.

GitHub Actions는 mod.json 버전과 일치하는 v 접두사 태그에서 검증 및 ZIP 빌드를 수행합니다. 로컬 빌드만으로 원격 공개 릴리스가 생성되는 것은 아닙니다.

MIT 라이선스는 이 저장소에서 작성한 코드와 문서에 적용합니다. Diablo II 및 게임 자산의 권리는 각 권리자에게 있습니다.
