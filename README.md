# Probabilistic Rune Downgrade — 0.1.0-alpha.2

**악마술사의 군림(Reign of the Warlock) 전용** 오프라인 D2RMM 시험판. **실제 게임 검증 전**입니다. 기본은 이스트(r24)→말(r23) 시제품입니다. `Ist-only prototype`을 끄면 엘드(r02)~조드(r33) 32등급을 생성합니다. 엘은 분해하지 않습니다.

룬 1개 + 낱장 감별 주문서 1개를 큐브에서 조합 → 분해 대기 아이템 → **다른 재료 없이 그 아이템 하나만 다시 조합**합니다.

| 결과 | 기본 확률 |
|---|---:|
| 바로 아래 룬 2개 | 50% |
| 바로 아래 룬 1개 | 25% |
| 원래 룬 1개 | 10% |
| 감별 주문서 1개 (꽝) | 15% |

첫 조합에서 두 재료를 소비합니다. 성공/유지에는 주문서를 돌려주지 않습니다. 모든 등급에 같은 확률, 두 개 결과는 항상 2개입니다. 네 확률은 0~100 정수이며 합이 100이 아니면 설치를 중단합니다. 임의 정규화하지 않습니다.

## 설치

1. 게임을 종료하고 오프라인 캐릭터와 공유 보관함을 백업합니다. 시험용 캐릭터를 권장합니다.
2. [GitHub 사전 릴리스](https://github.com/k0102575/d2rmm-rune-gamble/releases/tag/v0.1.0-alpha.2)의 Assets에서 `ProbabilisticRuneDowngrade-0.1.0-alpha.2.zip`을 받아 **D2RMM 루트 폴더**에 풉니다. `mods/ProbabilisticRuneDowngrade/mod.json`이 있어야 합니다.
3. D2RMM 1.9 이상에서 모드를 선택합니다. 기본 `Ist-only prototype`을 유지합니다. 악마술사의 군림 데이터 경로 `global/excel`만 수정하며 경로 선택 옵션은 없습니다. 기존 레저렉션 캐릭터는 지원하지 않습니다. 실제 게임 검증은 아직 수행하지 않았습니다.
4. Install Mods로 새로 빌드하고 D2RMM 설정에 맞게 오프라인 게임을 실행합니다. 설치 오류가 나면 오류 전체와 게임/D2RMM 버전을 기록합니다.
5. [짧은 게임 검증 절차](docs/TESTING.ko.md)에 따라 네 결과의 100% 설정·저장 및 재접속을 확인하고 기본 확률로 10~20회 정도 사용합니다. 대량 반복·결과별 집계는 필요하지 않습니다. 전체 등급 검증은 이후 선택 사항입니다.

## 저장 호환성과 다른 모드

대기 아이템은 새 3글자 코드와 독립 아이템 타입을 사용하고 룬/참 타입을 상속하지 않습니다. 입력 룬의 아이콘/HD 자산을 게임 설치에서 재사용하고, 이름은 `이스트룬 — 분해 대기`처럼 구분합니다. 장착·소켓·사용·판매점 생성용 설정은 부여하지 않습니다. 일반 룬은 수정하지 않습니다.

**모드 제거, 모드 순서 변경, 다른 스탯 추가 모드 설치, 게임 업데이트 전 모든 대기 아이템을 반드시 처리하고 백업하세요.** 스탯 ID는 현재 테이블 끝에 동적 추가됩니다. 순서/테이블 변경으로 ID가 바뀌면 대기 아이템이 잘못 해석되거나 저장을 읽지 못할 수 있습니다. 새 아이템 코드의 기반 행 위치도 바뀔 수 있습니다. 대기 상태를 유지한 채 설정만 바꾸면 저장된 1~100 값에 새 확률을 적용하므로 결과가 재해석됩니다. 난수는 첫 조합에서 고정되며 두 번째 조합에서 새 추첨하지 않습니다.

기존 Rune Downgrade, 룬 겹치기, 단일 룬 업그레이드, 타락/대규모 모드는 함께 끄고 시험하세요. 기존 조합 우선순위와 범용 아이템 조합은 충돌할 수 있습니다. 모드 순서만으로 안전을 보장하지 않습니다. 스택형 룬/주문서와 네임스페이스 충돌은 감지 시 중단합니다. 뒤에 설치되는 모드가 만드는 충돌까지 감지할 수는 없습니다.

## 개발 및 검증

Node.js 18+에서 `node tools/verify.mjs`, Python 3에서 `python3 tools/build.py`를 실행합니다. 기본 테스트는 저장소에 포함한 실제 공개 테이블의 헤더를 사용하는 **합성 fixture**입니다. `/tmp/rg-*.txt` 조사 테이블이 모두 있으면 공개 Reimagined 테이블로도 설치 생성기를 실행합니다. 원본 게임 테이블 전체는 저장소나 ZIP에 포함하지 않습니다.

검증 결과와 근거: [LOCAL_VALIDATION.json](docs/LOCAL_VALIDATION.json), [구현 및 조사](docs/IMPLEMENTATION.md). 로컬 PASS는 게임 동작 보증이 아닙니다. D2RMM 앱 실행·CASC 추출·게임 실행은 이 환경에서 수행하지 않았습니다.

MIT 라이선스는 이 저장소에서 작성한 코드·문서에 적용합니다. Diablo II 및 게임 자산의 권리는 각 권리자에게 있습니다. GitHub Releases는 게임 검증 전인 사전 릴리스로 배포합니다. Nexus 업로드는 진행하지 않습니다.

데이터 모드는 게임 실행이나 DLC 구매 여부를 검사하지 않습니다. 악마술사의 군림용 데이터만 생성하며, 해당 버전의 오프라인 캐릭터에서 사용해야 합니다.

## GitHub 릴리스

`mod.json`의 버전과 일치하는 `v` 접두사 태그를 push하면 GitHub Actions가 합성 fixture 검증과 ZIP 빌드를 수행합니다. 설치 ZIP과 SHA-256 파일을 초안에 업로드한 뒤 사전 릴리스로 게시합니다. 릴리스 설명은 `docs/RELEASE_NOTES.ko.md`에 있습니다. 다음 릴리스 전에는 버전과 설명을 함께 갱신하세요.
