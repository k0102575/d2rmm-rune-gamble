# 참고 모드 권한 확인 및 미발송 연락 초안

## 확인 기록

- 대상: Corruption Shards for RoTW / 제작자 rogeriogmm.
- 공식 주소: https://www.nexusmods.com/diablo2resurrected/mods/1051
- 2026-11-06: 공식 주소에 읽기 요청했으나 환경 프록시에서 `CONNECT tunnel failed, response 403`. 본문·Permissions and credits·현행 사이트 정책을 읽지 못했다. 이는 원작자가 접근이나 이용을 거부했다는 뜻이 아니다.
- 이전 대화의 '크레딧 조건으로 허용'과 오래된 수집 페이지의 제한 문구는 현행 권한 확인 근거로 확정하지 않는다.
- 현재 원작자에게 연락·허락을 받지 않았다. 아래 문구는 초안이며 발송하지 않았다.
- 사용자 설명상 착안한 것은 두 단계 조합 방식이며 원본 코드·이미지·파일을 복사해 배포하지 않았다. 이번 검토에서 현재 코드의 두 단계 구조는 확인했으나 참고 모드 원문과의 전수 대조는 하지 못했다.

## 게시 전 확인 절차

1. 공식 페이지 본문 및 Permissions and credits를 직접 열어 URL·확인 일시·정확한 원문을 저장한다. 로그인 여부와 파일/버전별 별도 조건도 기록한다.
2. '아이디어 참고', '코드·파일 사용', '이미지 사용'을 구분해 실제 배포물과 대조한다. 원작의 파일을 향후 추가한다면 그 자산에 적용되는 조건을 다시 확인한다.
3. 현재 본문과 권한란이 충돌하거나 적용 범위가 불명확하면 관련 문장을 인용해 원작자에게 문의한다. 답변 전 허락을 받았다고 표시하지 않는다. 단순 착안에 별도 허가가 반드시 필요하다고 법적으로 단정하지도 않는다.
4. 실제 연락은 사용자의 별도 발송 요청 후에만 한다. 답변·조건·원작자가 원하는 표기를 보관하고 크레딧을 갱신한다.
