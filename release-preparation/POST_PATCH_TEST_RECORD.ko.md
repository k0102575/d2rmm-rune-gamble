# 3.4 적용 후 실제 게임 검증 기록 — 미실행 양식

이 문서의 빈칸은 통과 기록이 아니다. 기존 검증은 `ProbabilisticRuneDowngrade/docs/TESTING.ko.md`를 참조한다. 패치 배포일과 래더 시작일은 서로 구분해 공식 근거를 확인한다.

## 실행 환경

- 일시·시간대: 미기록
- 게임 표시 버전 / 정확한 빌드: 미기록
- D2RMM 버전: 미기록
- 소스 커밋 / 사용 ZIP / SHA-256: 미기록
- 단독 또는 병용 / 전체 활성 모드 버전·설치 순서: 미기록
- 백업 및 시험용 세이브 준비: 미확인
- 패치 배포일 공식 근거 / 래더 시작일 공식 근거: 미확인

각 설정 변경 전에 대기 아이템을 처리하고 게임을 종료한 뒤 D2RMM 재설치. 결과 순서는 하위 2개 / 하위 1개 / 반환 / 꽝.

| 검사 | 설정 | 상태 / 실제 횟수·관찰·증거 |
|---|---|---|
| 단독 네 결과와 수량 | 각 결과 100% | 미실행 |
| 단독 기본값, 대기 생성·단독 재조합 | 50/25/10/15 | 미실행 |
| 병용 네 결과와 수량 | 각 결과 100% | 미실행 |
| 병용 한 옵션만 0% (下2 없음) | 0/34/33/33 | 미실행 |
| 병용 한 옵션만 0% (下1 없음) | 33/0/34/33 | 미실행 |
| 병용 한 옵션만 0% (반환 없음) | 33/33/0/34 | 미실행 |
| 병용 한 옵션만 0% (꽝 없음) | 34/33/33/0 | 미실행 |
| 전체 등급: 조드부터 엘, 엘 입력 불가 | 설정 및 확인 등급 기록 | 미실행 |
| 결과 룬: 룬워드·소켓·기존 업그레이드 | 사용 룬·조합 기록 | 미실행 |
| 룬 창고·겹치기 | 해당 모드 병용 시 | 미실행 |
| 결과 룬 저장·종료·재접속 | 저장 전후 기록 | 미실행 |
| 대기 아이템 저장·종료·재접속·단독 재조합 | 확률·모드 순서 유지 | 미실행 |
| Relics 병용 표시·재조합·설치 로그 | 전체 구성·순서 기록 | 미실행 |

반복 횟수만으로 확률의 정확성을 입증하지 않는다. 짧은 시험에서 0% 결과가 나오지 않았다는 사실도 자동 전수 검사와 구분한다. 실패 시 세이브 복사본·설치 로그·설정·재현 순서를 보관하고 공개 여부를 재평가한다. 수정을 했다면 관련 검사와 빌드를 다시 실행한다.

최종 공개 판단: 보류 — 패치 후 검사 및 권한 확인 전.
